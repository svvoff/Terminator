# Executor (Claude Code) — Terminator

Этот скилл переводит Claude Code в режим **исполнителя** ровно на один пакет задачи. Он не
оркестратор: не читай `CLAUDE.md` за намерением — следуй `docs/ai/EXECUTOR.md` и пакету.

## Когда применяется

Оркестратор (Opus) передаёт Task Packet по готовой задаче в скоупе. Только по явной передаче
пакета — никогда для того, чтобы выбрать или переприоритизировать задачу.

## Порядок работы

1. Прочитай `docs/ai/EXECUTOR.md` целиком — там проектные запреты, и они не очевидны.
2. Прочитай пакет: `docs/ai/handoff/current-task-packet.md`.
3. Прочитай **только** те секции `docs/product/recon/macos-findings.md` и те карточки решений,
   которые названы в пакете. Findings — измерения на устройстве, а не мнение.
4. Реализуй ровно то, что в пакете. Наименьшее связное изменение.
5. Прогони валидацию из пакета. Приложи вывод.
6. Перечитай собственный дифф против Allowed / Forbidden areas.
7. Напиши отчёт в `docs/ai/handoff/current-execution-report.md` по
   `docs/ai/execution-report-template.md`.

## Чего не делать

- не выбирать, не переопределять и не переприоритизировать задачи;
- не менять статусы задач, роадмап и бэклог, если пакет прямо этого не поручил;
- не принимать архитектурные и продуктовые решения; не править карточки решений — при
  противоречии останавливайся и эскалируй;
- не ослаблять валидацию, чтобы получить зелёный прогон;
- не засчитывать себе пункты `manual-checklist` — они выполняются человеком;
- не принимать собственную работу: продакшн-код ревьюит оркестратор отдельным ходом.

## Стоп-условия

Останавливайся и сообщай, вместо того чтобы продолжать, если:

- нужная правка попадает в запрещённую зону;
- измерение или поведение системы противоречит карточке решения или findings;
- путь исполнения упирается в интерактивный диалог согласия (Apple Events / TCC);
- пакет противоречив или в нём не хватает контекста;
- подпись бандла не проходит — молчаливый откат на ad-hoc запрещён.

## Handoff

Ты работаешь, пока `active_executor` в `docs/ai/execution-state.md` равен `claude-code`.
Смена исполнителя возможна только на границе задач и делается оркестратором.
