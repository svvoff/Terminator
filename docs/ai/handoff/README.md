# handoff/ — шина между ролями

Фиксированные имена файлов, перезаписываются на каждом цикле. Здесь лежит **только текущий
цикл**; долговременная история — в `../execution-state.md`, `../execution-log/` и в карточках
из `tasks/done/`.

| Файл | Кто пишет | Что это |
|---|---|---|
| `current-task-packet.md` | оркестратор | задание исполнителю; самодостаточно |
| `current-execution-report.md` | исполнитель | что сделано и чем это доказано |
| `current-diff.patch` | оркестратор | снимок диффа для ревью, пересобирается на каждый раунд |
| `migration-prompt.md` | оркестратор | bootstrap новой сессии; пишется по триггеру «подготовься к переезду», не создаётся заранее |

Исполнитель пишет ровно один файл — свой отчёт.

Параллельные потоки задач добавляют к имени короткий суффикс
(`current-task-packet-<slug>.md`); такой пакет обязан назвать собственный путь отчёта и явно
запретить файлы соседнего потока.

Не путать с mode-ledger оркестратора: в этом проекте режим один (primary), и каталога
`docs/ai/orchestrator/` нет.
