## Гейты риска

`risk: high`, **зона 4** (завершение чужих процессов). **Разрешение пользователя получено
2026-08-27** вместе с выбором пяти подопытных: TextEdit, Calculator, VLC, Todoist, Obsidian.
Каждый открывался оператором специально для задачи.

`tccutil reset AppleEvents com.svvoff.terminator.probe`, 17 вызовов, все с идентификатором.
Форма без идентификатора не использовалась ни разу. Зоны 1, 2, 5, 6 не участвовали.
