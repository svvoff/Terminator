## Измерение, висящее на обеих карточках

Срабатывает ли `.onAppear` содержимого `MenuBarExtra` на **каждое** открытие поповера. На нём
держатся и чтение статуса автозапуска, и `reloadFromDisk()` из TASK-006 — то есть её пункт 14.
Исполнитель снять его не смог и честно доложил: программного способа открыть поповер стиля
`.window` нет, а синтетический клик требует Accessibility, то есть интерактивного диалога
согласия. Проверка: три открытия должны дать три строки `login item status:` в логе.
